Por qué este curso

Nada de teoría suelta. Cada clase termina con algo funcionando: un repositorio, una página o un sitio publicado que puedes mostrar.

Aprendes haciendo

Escribes tus propios comandos de Git desde el primer día, en tu propia máquina.

Publicas de verdad

Tu proyecto queda en línea con una URL real que puedes compartir con quien quieras.

Flujo profesional

Usas GitHub y Netlify tal como se usan en equipos de trabajo reales.

Actualizas sin miedo

Cada cambio que subes se despliega solo. Ves el resultado en minutos.

El temario, en cuatro pasos

  1. 01

    Tu página local

    Creas el archivo index.html de tu proyecto y lo abres en el navegador.

  2. 02

    Git y tu primer commit

    Inicializas el repositorio local y guardas el historial de tu proyecto.

  3. 03

    Subir a GitHub

    Conectas tu repositorio local con uno remoto y subes tu código con git push.

  4. 04

    Desplegar en Netlify

    Conectas tu repositorio a Netlify y tu sitio queda publicado, con despliegue automático en cada cambio.
